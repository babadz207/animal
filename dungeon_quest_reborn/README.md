# Dungeon Quest Reborn - Roblox Auto-Farm & Kaitun Script

Thư mục dành riêng cho script tự động chơi **Dungeon Quest Reborn** trên Roblox.

## Cấu trúc thư mục

- `main.lua`: Core script chính (Auto Dungeon, Auto Skill, Auto Loot, Auto Sell, UI Dashboard).
- `research/`: Chứa các script soi Remote, Instance & Data Dump của Dungeon Quest Reborn.

## Hướng dẫn sử dụng

Chạy bằng loadstring trên các Executor (Delta, Fluxus, Solara, Wave, Mobile...):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/babadz207/animal/main/dungeon_quest_reborn/main.lua"))()
```
